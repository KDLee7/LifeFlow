# Props

## What are Props?

Props (short for **properties**) are how information is passed from one component to another.

Think of props as **arguments** that are passed into a function.

A parent component sends data to a child component through props.

---

# Why Do We Use Props?

Props allow components to be reusable.

Instead of creating a new component for every piece of data, we create one component and supply it with different information.

Without props:

```jsx
<h2>Winston</h2>
<h2>Bella</h2>
<h2>Max</h2>
```

With props:

```jsx
<Pet name="Winston" />
<Pet name="Bella" />
<Pet name="Max" />
```

One component can display many different pets.

---

# Parent and Child Components

A **parent component** sends data.

A **child component** receives data.

Example:

```
App.jsx
    │
    │ sends props
    ▼
Pet.jsx
```

The flow of data is always:

```
Parent
    ↓
Child
```

Props only flow **one direction**.

---

# Passing Props

The parent component passes information as attributes.

Example:

```jsx
<Pet
    name="Winston"
    age={1}
    color="Black and Tan"
/>
```

Notice:

Strings use quotation marks.

```jsx
name="Winston"
```

JavaScript values use curly braces.

```jsx
age={1}
```

---

# Receiving Props

The child component receives the information inside a parameter named props.

```jsx
function Pet(props) {
    return (
        <>
            <h2>{props.name}</h2>
            <p>{props.age}</p>
            <p>{props.color}</p>
        </>
    );
}
```

Think of **props** as an object that contains everything sent by the parent.

---

# The Props Object

When App.jsx sends:

```jsx
<Pet
    name="Winston"
    age={1}
    color="Black and Tan"
/>
```

React creates an object that looks like this:

```javascript
props = {
    name: "Winston",
    age: 1,
    color: "Black and Tan"
}
```

Inside the component we access the values like this:

```jsx
props.name

props.age

props.color
```

---

# Destructuring Props

Instead of writing:

```jsx
function Pet(props)
```

we learned a cleaner approach.

```jsx
function Pet({ name, age, color }) {
    return (
        <>
            <h2>{name}</h2>
            <p>{age}</p>
            <p>{color}</p>
        </>
    );
}
```

This is called **destructuring**.

It makes the code easier to read because we no longer need to write:

```jsx
props.name
props.age
props.color
```

---

# Strings vs JavaScript

Strings use quotes.

```jsx
name="Winston"
```

Numbers use curly braces.

```jsx
age={1}
```

Variables also use curly braces.

```jsx
age={dogAge}
```

Expressions use curly braces.

```jsx
age={1 + 1}
```

---

# Props are Read-Only

A component should never change the props it receives.

Incorrect:

```jsx
props.name = "Max";
```

Props belong to the parent component.

The child only displays them.

---

# Reusing Components

Instead of creating three different components:

```jsx
<Winston />

<Bella />

<Max />
```

We use one component.

```jsx
<Pet
    name="Winston"
    age={1}
    color="Black and Tan"
/>

<Pet
    name="Bella"
    age={3}
    color="Brown"
/>

<Pet
    name="Max"
    age={5}
    color="White"
/>
```

This is one of the biggest advantages of React.

# Common Mistakes

## Forgetting Curly Braces

Incorrect

```jsx
age="1"
```

Correct

```jsx
age={1}
```

---

## Misspelling a Property

Parent

```jsx
name="Winston"
```

Child

```jsx
props.names
```

Result:

```
undefined
```

The property names must match exactly.

---

## Forgetting to Receive Props

Incorrect

```jsx
function Pet() {

}
```

Correct

```jsx
function Pet(props) {

}
```

or

```jsx
function Pet({ name }) {

}
```

---

## Trying to Change Props

Incorrect

```jsx
props.age = 5;
```

Props should never be modified by the child component.

# Vocabulary

Props

Information passed from one component to another.

Parent Component

Child Component

Destructuring

Read-Only

Data that should not be modified.
