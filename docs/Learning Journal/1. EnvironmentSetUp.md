## Node.js

Purpose:
Node.js allows JavaScript to run outside of a web browser.

React depends on Node because it provides npm (Node Package Manager), which installs libraries and project dependencies.

Verify Installation

```bash
node -v
```

Verify npm

```bash
npm -v
```

---

## Git

Purpose:
Git tracks changes made to the project.

Later it will allow me to:

- Save project history
- Undo mistakes
- Upload projects to GitHub
- Collaborate with others

Verify Installation

```bash
git --version
```

# Why We Chose Vite

Instead of Create React App, we used Vite.

Benefits:

- Faster startup
- Faster builds
- Simpler setup
- Modern React standard

---

# Creating the LifeFlow Project

Open a terminal.

Create the project.

```bash
npm create vite@latest
```

During setup choose:

Project Name

```
lifeflow
```

Framework

```
React
```

Variant

```
JavaScript
```

---

Move into the project folder.

```bash
cd lifeflow
```

Install project dependencies.

```bash
npm install
```

---

# Running the Development Server

Start the project.

```bash
npm run dev
```

Open the browser using the address shown in the terminal.

Usually:

```
http://localhost:5173
```

If everything is working correctly, I should see the default Vite React page.

---

# Understanding the Project Structure

LifeFlow

```
lifeflow/

├── node_modules/
├── public/
├── src/
│   ├── App.jsx
│   └── main.jsx
├── package.json
└── vite.config.js
```

## node_modules

Contains every library used by the project.

Never edit anything inside this folder.

---

## public

Contains static files.

Examples:

- images
- icons
- fonts

---

## src

This is where almost all of my work will happen.

---

## App.jsx

The main React component.

Think of it as the starting page of the application.

---

## main.jsx

Starts the React application and connects App.jsx to the browser.

---

# New Vocabulary

React

A JavaScript library used to build user interfaces.

Node.js

Allows JavaScript to run outside the browser.

npm

Node Package Manager.

Used to install packages and dependencies.

Vite

A tool that creates and runs modern React projects.

Component

A reusable piece of a user interface.

Dependency

A library that the project needs in order to work.
