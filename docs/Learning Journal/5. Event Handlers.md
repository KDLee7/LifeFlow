What is an event handler?

An event handler is a function that React calls when an event occurs, such as a button click.

Key Concepts
Functions can be passed as values.
onClick={handleButtonClick} passes a function reference.
onClick={handleButtonClick()} runs the function immediately.
Parentheses () execute a function.
Without parentheses, React stores the function and calls it when the event happens.
Naming Convention

Common React event handler names:

handleClick
handleSubmit
handleSave
handleDelete

Functions should describe the action they perform.
