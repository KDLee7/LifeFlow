Objective

Learn how React stores and organizes multiple pieces of related data.

Before This Lesson

I stored tasks as simple strings.

const tasks = [
  "Learn React Components",
  "Build Navigation",
  "Learn CSS Flexbox"
]
Problem

A string can only store one piece of information.

I couldn't keep track of:

Whether the task was completed
A unique ID
A due date
A priority
Notes
What is an Array?

An array stores multiple items in one variable.

Example:

const dogs = [
  "Winston",
  "Charlie",
  "Buddy"
]

Think of an array as a list.

dogs
│
├── Winston
├── Charlie
└── Buddy
What is an Object?

An object stores related information together.

Example:

const dog = {
  name: "Winston",
  breed: "Yorkshire Terrier",
  age: 1
}

Instead of storing one value, an object stores many properties.

dog
│
├── name
├── breed
└── age
Arrays of Objects

React applications often store arrays of objects.

Example:

const tasks = [
  {
    id: 1,
    title: "Learn React Components",
    completed: false,
  },
  {
    id: 2,
    title: "Build Navigation",
    completed: false,
  },
  {
    id: 3,
    title: "Learn CSS Flexbox",
    completed: false,
  }
]

This combines both concepts.

tasks
│
├── Task
│     ├── id
│     ├── title
│     └── completed
│
├── Task
│     ├── id
│     ├── title
│     └── completed
│
└── Task
      ├── id
      ├── title
      └── completed
Why This Is Better

Each task now contains everything related to that task.

Instead of:

"Learn React"

I now have:

{
  id: 1,
  title: "Learn React",
  completed: false
}

This makes it possible to:

Track completion
Add due dates
Add priorities
Add notes
Uniquely identify each task
Key Terms
Array

Stores multiple values.

Example:

const colors = ["Red", "Blue", "Green"]
Object

Stores related information together.

Example:

const person = {
  name: "Kim",
  job: "Developer"
}
Property

Each piece of information inside an object.

Example:

person.name

returns
Kim

My Takeaway

React applications are built around data.

Instead of storing separate pieces of information, I should group related data together inside objects and store those objects in arrays when there are multiple items.

Things to Remember

✅ Arrays store lists.
✅ Objects store related information.

✅ Arrays can contain objects.

✅ React applications commonly use arrays of objects.
