# JSX (JavaScript XML)

## What is JSX?

JSX (JavaScript XML) is a special syntax used by React that allows us to write HTML-like code inside JavaScript.

Although it looks like HTML, JSX is actually JavaScript.

Example:

```jsx
function App() {
    return (
        <h1>Hello World</h1>
    );
}
```

The `<h1>` looks like HTML, but React converts it into JavaScript behind the scenes.

---

# Why Do We Use JSX?

Without JSX, creating HTML with JavaScript is difficult to read.

Example without JSX:

```javascript
React.createElement(
    "h1",
    null,
    "Hello World"
);
```

With JSX:

```jsx
<h1>Hello World</h1>
```

JSX is much cleaner and easier to understand.

---

# JSX Looks Like HTML

Example:

```jsx
<div>
    <h1>LifeFlow</h1>
    <p>Welcome back!</p>
</div>
```

Even though it looks like HTML, this code is written inside a JavaScript file.

---

# JSX Must Return One Parent Element

A component can only return one parent element.

❌ Incorrect

```jsx
return (
    <h1>Hello</h1>
    <p>Welcome</p>
);
```

React doesn't know which element is the "top level."

---

## Correct

Wrap everything inside one parent element.

```jsx
return (
    <div>
        <h1>Hello</h1>
        <p>Welcome</p>
    </div>
);
```

Or use a React Fragment.

```jsx
return (
    <>
        <h1>Hello</h1>
        <p>Welcome</p>
    </>
);
```

---

# What is a Fragment?

A Fragment groups multiple elements together without adding another HTML element to the page.

Instead of creating an unnecessary `<div>`, we can use:

```jsx
<>
</>
```

This keeps the HTML cleaner.

---

# Embedding JavaScript

One of the biggest advantages of JSX is that it allows JavaScript inside HTML-like code.

JavaScript is placed inside curly braces.

Example:

```jsx
const name = "Kim";

return (
    <h1>Hello {name}</h1>
);
```

Output:

```
Hello Kim
```

---

# Using Variables

```jsx
const age = 30;

return (
    <p>Age: {age}</p>
);
```

---

# Using Math

```jsx
return (
    <p>{2 + 2}</p>
);
```

Output:

```
4
```

---

# Using Expressions

```jsx
const firstName = "Kim";
const lastName = "Lee";

return (
    <h1>{firstName + " " + lastName}</h1>
);
```

Output:

```
Kim Lee
```

---

# Using JavaScript Functions

```jsx
function greeting() {
    return "Welcome!";
}

return (
    <h1>{greeting()}</h1>
);
```

---

# JSX Attributes

HTML uses:

```html
class="container"
```

JSX uses:

```jsx
className="container"
```

Why?

Because **class** is already a reserved word in JavaScript.

---

HTML

```html
<label for="email">
```

JSX

```jsx
<label htmlFor="email">
```

---

# Self-Closing Tags

HTML

```html
<img>
```

JSX

```jsx
<img />
```

Every self-closing element must end with:

```
/
```

Examples

```jsx
<img />

<input />

<hr />

<br />
```

---

# Comments

HTML

```html
<!-- Comment -->
```

JSX

```jsx
{/* Comment */}
```

# Common Mistakes

## Multiple Parent Elements

❌

```jsx
<h1>Hello</h1>
<p>Welcome</p>
```

✔

```jsx
<>
    <h1>Hello</h1>
    <p>Welcome</p>
</>
```

---

## Forgetting Curly Braces

Incorrect

```jsx
<h1>name</h1>
```

Correct

```jsx
<h1>{name}</h1>
```

---

## Using class Instead of className

Incorrect

```jsx
<div class="box">
```

Correct

```jsx
<div className="box">
```

---

## Forgetting Self-Closing Tags

Incorrect

```jsx
<img>
```

Correct

```jsx
<img />
```

---

# Vocabulary

JSX

A syntax that lets us write HTML-like code inside JavaScript.

Fragment

Groups multiple elements without adding extra HTML.

Expression

JavaScript code that produces a value.

Curly Braces

Allow JavaScript to be written inside JSX.

className

React's replacement for the HTML class attribute.

# What We Used in LifeFlow

We wrote JSX inside our React components.

Example:

```jsx
function Header() {
    return (
        <>
            <h1>LifeFlow</h1>
            <p>Welcome back, Kim!</p>
        </>
    );
}
```

We also used JSX to display values from props.

```jsx
<h2>{name}</h2>

<p>{age}</p>

<p>{color}</p>
```

This showed how JSX can combine HTML with JavaScript.

---

# Key Takeaways

✔ JSX looks like HTML but is actually JavaScript.

✔ Components return JSX.

✔ JSX must have one parent element.

✔ React Fragments prevent unnecessary HTML.

✔ JavaScript is written inside curly braces.

✔ JSX uses className instead of class.

✔ Self-closing tags must end with />.

# Reflection

JSX is one of React's most important features because it allows HTML and JavaScript to work together naturally.

Instead of separating structure and logic into different files, JSX combines them into one readable, reusable component.
