Objective

Learn how React uses .map() to automatically create multiple components from an array of data.

Before This Lesson

I created one TaskCard manually.

<TaskCard
  title="Today's Focus"
  focus="Learn React Components"
/>

This worked, but if I wanted ten tasks, I would have to write ten TaskCard components.

The Problem

Imagine having 100 tasks.

Without .map(), I would need to write:

<TaskCard />
<TaskCard />
<TaskCard />
<TaskCard />
<TaskCard />
...

This would create unnecessary duplicate code.

The Solution

Instead of creating each component manually, React can build them automatically.

{tasks.map((task) => (
  <TaskCard
    key={task.id}
    title="Today's Focus"
    focus={task.title}
    completed={task.completed}
    handleButtonClick={() => handleButtonClick(task.id)}
  />
))}
What Does .map() Do?

.map() loops through every item in an array.

For each item, it creates something new.

Think of it like this:

React reads them one at a time.

   ↓
Create TaskCard

Breaking It Down
tasks.map((task) => (

This means:

"Go through every task in the tasks array."

Each time React loops, task represents one object.

First loop:

task = {
  id: 1,
  title: "Learn React Components",
  completed: false
}

Second loop:

task = {
  id: 2,
  title: "Build Navigation",
  completed: false
}

Third loop:

task = {
  id: 3,
  title: "Learn CSS Flexbox",
  completed: false
}
Reading Object Properties

Instead of writing:

focus="Learn React Components"

I now use:

focus={task.title}

React replaces it automatically.

First loop:

focus="Learn React Components"

Second loop:

focus="Build Navigation"

Third loop:

focus="Learn CSS Flexbox"
Why Do We Need a Key?

Each component needs a unique identifier.

key={task.id}

React uses the key to know which component belongs to which task.

Without a key, React shows a warning.

Keys help React update only the items that changed.

My Takeaway

React works best when I focus on the data instead of manually building the interface.

If my data changes, React rebuilds the UI automatically.

Things to Remember

✅ .map() loops through every item in an array.

✅ It creates something new for every item.

✅ React commonly uses .map() to create components.

✅ Every component created with .map() needs a unique key.
