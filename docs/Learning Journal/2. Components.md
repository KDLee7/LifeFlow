# Components

## What is a Component?

A component is a reusable piece of the user interface (UI).

Think of components like LEGO bricks. Each brick is a small piece that can be combined with others to build something much larger.

Instead of writing one huge HTML page, React applications are built by combining many small components.

Example:

A webpage might contain:

- Header
- Navigation Bar
- Sidebar
- Dashboard
- Footer

Each one can be its own component.

---

# Why Do We Use Components?

Components make code:

- Reusable
- Easier to read
- Easier to maintain
- Easier to debug
- Easier to organize

Instead of rewriting the same code multiple times, we write it once and reuse it.

---

# A Real-World Example

Imagine building a house.

You don't build the entire house as one piece.

Instead, it's made of:

- Walls
- Doors
- Windows
- Roof
- Cabinets

Each part has one job.

React works the same way.

A complete application is built from many small components.

---

# What Does a Component Look Like?

A basic component is simply a JavaScript function that returns JSX.

Example:

```jsx
function Header() {
    return (
        <h1>LifeFlow</h1>
    );
}

export default Header;
```

Every component follows the same pattern.

1. Create a function.
2. Return JSX.
3. Export it.

---

# Naming Components

Component names ALWAYS begin with a capital letter.

Correct

```jsx
Header
Footer
Dashboard
PetCard
```

Incorrect

```jsx
header
footer
dashboard
```

React uses capitalization to distinguish components from normal HTML tags.

# Creating a Component

We created a new folder inside src called:

```
components
```

Example:

```
src/

Header.jsx
```

Keeping components together makes projects easier to organize.

---

# Importing Components

Before a component can be used, it must be imported.

Example

```jsx
import Header from "./components/Header";
```

Think of import as saying:

"I want to use this file."

---

# Using a Component

Once imported, a component behaves like an HTML tag.

```jsx
function App() {
    return (
        <>
            <Header />
        </>
    );
}
```

Notice the self-closing tag.

React treats this as:

"Display the Header component here."

---

# Exporting Components

Every component should be exported so other files can use it.

```jsx
export default Header;
```

Think of export as saying:

"This file is available for other files to use."

# Components Can Be Reused

Instead of writing the same HTML repeatedly:

```html
<h2>Dog</h2>

<h2>Dog</h2>

<h2>Dog</h2>
```

We create one component.

```jsx
<Dog />
```

Then use it as many times as needed.

```jsx
<Dog />

<Dog />

<Dog />
```

This is one of React's biggest strengths.

---

# Rules for Components

✔ Start with a capital letter.

✔ Return JSX.

✔ Return only one parent element.

✔ Export the component.

✔ Import it before using it.

---

# Common Mistakes

## Forgetting to Export

Wrong

```jsx
function Header() {

}
```

Correct

```jsx
export default Header;
```

---

## Forgetting to Import

Wrong

```jsx
<Header />
```

Correct

```jsx
import Header from "./components/Header";
```

---

## Lowercase Component Names

Wrong

```jsx
<header />
```

React thinks this is an HTML element.

Correct

```jsx
<Header />
```

---

## Returning Multiple Parent Elements

Wrong

```jsx
return (
    <h1>Hello</h1>
    <p>Welcome</p>
)
```

Correct

```jsx
return (
    <>
        <h1>Hello</h1>
        <p>Welcome</p>
    </>
)
```

# Vocabulary

Component

A reusable piece of a user interface.

JSX

HTML-like syntax written inside JavaScript.

Import

Allows one file to use another file.

Export

Makes a file available for other files to use.

Parent Element

The single outer element returned by a component.

Fragment

```
<>
</>
```

Allows multiple elements to be grouped without creating an extra HTML element.
